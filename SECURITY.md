# Security policy

Report workflows security issues privately using **Security → Advisories → Report a vulnerability** in the [`zazathomas/workflows`](https://github.com/zazathomas/workflows) repository.
Do not open a public issue or send a fork-specific report to upstream Argo Workflows.
The repository owner must enable private vulnerability reporting before the first public release.

Each image released under this policy supports the upstream Argo Workflows releases listed in [the compatibility matrix](docs/compatibility.md), currently v4.1.0 through v4.1.6.
For a vulnerability in unchanged upstream code, report it to [upstream Argo Workflows](https://github.com/argoproj/argo-workflows/security/advisories/new) and contact the fork maintainers privately so the image can be updated.
See [workflows security](docs/fork-security.md) for deployment guidance.
